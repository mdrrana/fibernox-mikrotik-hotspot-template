# 🚀 FiberNox — Responsive MikroTik Hotspot Login Template

A sleek, responsive, and mobile-friendly MikroTik RouterOS Hotspot login template built for modern Internet Service Providers (ISPs). Fully optimized for integration with **[FiberNox ISP Billing ERP](https://fibernox.com)**.

---

### 🌐 Official Network Ecosystem
* 📡 **ISP Billing & Radius ERP:** [https://fibernox.com](https://fibernox.com)
* ☁️ **Cloud Infrastructure & VPS:** [https://jinix.cloud](https://jinix.cloud)
* 📱 **Transactional SMS & OTP Gateway:** [https://smsbd.asia](https://smsbd.asia)

---

### ✨ Features
- **Mobile-First & Ultra Fast:** Lightweight design that loads in milliseconds inside captive portals.
- **Direct MFS & OTP Login:** Ready for seamless integration with bKash, Nagad, and SMSBD.Asia OTP.
- **FiberNox Integration:** Native support for FiberNox AAA RADIUS & MikroTik v6/v7 REST API auto-cutoff.
